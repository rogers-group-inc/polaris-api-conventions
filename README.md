# polaris-api-conventions — moved to polaris-toolbox

**This plugin is archived.** Its skill now lives in
[polaris-toolbox](https://github.com/rogers-group-inc/polaris-toolbox) as `polaris-api`,
alongside skills for manufacturer profiles, automations and automation scripts, and scripts
that apply and export them over the Polaris API. That repository was imported with this
one's history.

```
git clone https://github.com/rogers-group-inc/polaris-toolbox
claude --plugin-dir ./polaris-toolbox
```

The files here are left as they were at version 0.5.0 and are no longer updated: they
describe the Polaris API as of 2026-10-23.
